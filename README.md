# Content Output Coach 2.1

针对用户近期小红书创作问题的升级版。

## 新增的6项硬约束

1. 开头必须优先冲突/结果/反常识，避免“先交代背景”。
2. 有真实冲突和过程时，优先故事驱动，不默认写成教程。
3. 每篇必须提炼一个差异化亮点，并前置到标题/封面/首屏中的至少两个位置。
4. 标签默认控制在6～7个。
5. 评论引导从“你怎么看”升级为具体、可站队、与核心冲突相关的问题。
6. 压缩解释，让截图、案例和过程自己说话。

## 重要流程升级

标题、首屏、封面核心文案、故事结构必须在“内容冻结”前确定。

新的流程：

选题 → 冲突 → 差异化亮点 → 标题/封面 → 故事结构 → 正文 → 传播检查 → 内容冻结 → 图片 → 发布。

这样可以避免在做图片时再次修改正文，造成内容回流。

## 使用

开始小红书创作时说：

> 开始今天的小红书。

如果你觉得开头太平：

> 这个开头是不是太稳了？

如果你在做图片时又想改文章：

> 我又想改内容了。

如果一篇内容耗时过长：

> 复盘这篇小红书为什么这么慢。
